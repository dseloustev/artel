# skills/

Workflow skills — one folder per skill, `SKILL.md` inside. Installed, they surface as
`/artel:<name>`.

Empty until porting starts: entry points land in
[porting-plan Phase 4](../docs/porting-plan.md#phase-4--entry-point-orchestrators), stage
skills in [Phase 3](../docs/porting-plan.md#phase-3--stage-skills). Skills here are
orchestrators — they resolve ticket context, invoke agents, and report; they never inline the
agent's work.
